# 레퍼런스: paper-ink

미색 종이 바탕에 남색 잉크로 수식과 도형을 그리고, 주황과 노랑으로 한 군데만 짚는 세로 숏폼 수학 영상 두 편.

## 공통 성격

- 바탕은 한 가지 색(#F2F2F2 언저리)에 아주 옅은 종이 결(밝기 흔들림 표준편차 약 4). 그라데이션 없음.
- 글자와 선은 거의 전부 남색 한 가지. 강조색은 화면마다 하나만 쓴다.
- 한글은 둥글고 굵은 손글씨풍 고딕. 수식과 숫자는 LaTeX 세리프(Computer Modern 계열).
- 가운데 정렬, 여백이 넓다. 화면 하나에 정보 덩어리 하나.
- 그림자 · 테두리 상자 · 아이콘 없음.
