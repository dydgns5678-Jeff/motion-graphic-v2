# video.md

화면: 교실 TV, 가로 16:9. 학생이 맨 뒷자리에서도 글을 읽을 수 있어야 한다.

## 1. 글자 최소 크기

| 무엇 | 최소 | 이 영상 기본값 | 출처 |
|---|---|---|---|
| 읽는 글 (문장 · 설명) | 44px | 52px (`text-body`) | templates/look/design.md 양식 최소, docs/design.md 2장 |
| 쪽수 · 출처 · 라벨 | 32px | 36px (`text-label`) | 양식 최소, docs/design.md 2장 |
| 제목 | 72px | 72px (`text-title`) | docs/design.md 2장 |
| 수식 · 숫자 | 52px | 80px (`text-math`) | 읽는 글보다 작으면 안 된다 |
| 주황 글자 | 72px · 굵기 700 | 112px (판정 · 강조) | docs/design.md 1장 (주황 대비 2.15:1) |

- 크기는 1920×1080 화면 기준. 더 작은 화면으로 줄여 내보내도 비율은 그대로 둔다.
- 한 줄 최대 26자 (문장 최대 폭 1400px ÷ 52px).
- 읽는 글은 한 화면에 3줄까지. 넘으면 화면을 나눈다.
- 아래첨자 · 위첨자(지수)도 32px 아래로 내려가지 않게 한다.

## 2. 배경

선생님 답: **밝은 미색 종이** (기본값).

- 영상 처음부터 끝까지 `color-bg` #F2F2F2 + 종이 결 한 가지 (`src/parts/background.html`).
- 어두운 장면 · 검은 화면 · 색 바탕 장면을 넣지 않는다.
- 장면이 바뀌어도 바탕은 바뀌지 않는다. 바탕 위의 내용만 교차 사라짐으로 바뀐다 (docs/motion.md 2장 transition).
- 사진 · 그라데이션 바탕 없음.

## 3. 글자

| 규칙 | 값 |
|---|---|
| 글자색 | 읽는 글 · 제목 · 수식은 모두 `color-ink` #084A84 |
| 보조 글자색 | 쪽수 · 출처 · 라벨만 `color-ink-soft` #4A6F94 |
| 굵기 | 600(SemiBold) 이상. TV에서 가는 글자는 번진다. 400은 쓰지 않는다 |
| 한글 글꼴 | Pretendard (선생님 결정 2026-11-15) |
| 수식 · 숫자 글꼴 | Noto Serif KR |
| 강조 | 한 화면에 한 가지만: 노랑 형광 밑줄 **또는** 주황 낱말 **또는** 색 바뀜 |
| 주황 | 2~6글자, 72px 이상, 굵기 700. 문장을 주황으로 쓰지 않는다 |
| 줄바꿈 | 낱말 중간에서 바꾸지 않는다 (`word-break: keep-all`) |
| 정렬 | 가운데 정렬. 그림과 글을 좌우로 나눌 때만 글을 왼쪽 정렬 |

## 4. 화면 틀

선생님 답: **여백 두기** (기본값).

| 항목 | 값 | 출처 |
|---|---|---|
| 크기 | 1920×1080 | 양식 |
| 초당 프레임 | 60fps | 레퍼런스 A · B 모두 60fps (references/paper-ink/README.md). HyperFrames 새 프로젝트 기본값은 30fps이므로 프로젝트에서 60으로 바꿔 쓴다. 렌더가 너무 오래 걸리면 30fps로 낮출지 선생님에게 묻는다 |
| 좌우 여백 | 160px | docs/design.md 4장 `space-margin-x` |
| 위아래 여백 | 96px | docs/design.md 4장 `space-margin-y` |
| 비우는 양 | 화면 절반 이상 | docs/design.md 4장 구도 |
| 한 화면 정보 | 덩어리 하나 (제목+문장, 그림+이름, 용어+정의 중 하나) | docs/design.md 4장 구도 |
| 과목 · 단원 라벨 | 왼쪽 위 고정, 영상 내내 | src/parts/subject-label.html |
| 카메라 | 고정 | docs/motion.md 5장 |

### 첫 화면
- 과목 · 단원 라벨 + 소단원 제목 (`title-quote.html`의 제목 조각).

### 마지막 정리 화면
선생님 답: **그림 + 핵심 문장** (기본값). 레퍼런스 B 0:33~37.7 끝 화면을 본뜬 배치.

```
┌──────────────────────────────────────────┐
│ 수학 1 | 1. 소인수분해                      │  ← subject-label
│                                          │
│              [ 핵심 그림 ]                 │  ← figure-caption의 그림 조각, 높이 최대 520px
│                                          │
│              소단원 제목                    │  ← text-title 72px
│      핵심 문장 1~2줄 (강조 한 군데)          │  ← text-body 52px
│                교과서 p.00                 │  ← text-label 36px
└──────────────────────────────────────────┘
```

- 그림 위, 글 아래, 모두 가운데 정렬.
- 그림은 그 영상에서 이미 보여 준 그림 하나만. 새 그림을 넣지 않는다.
- 핵심 문장은 교과서 md의 문장 그대로, 쪽수와 함께.
- 강조는 한 군데 (주황 낱말 또는 노랑 밑줄).
- 머무는 시간 4.4초 이상 (docs/motion.md 4장).

## 5. 표기 (교과서 표기 그대로)

화면 글은 `docs/textbook/` md의 표기를 그대로 따른다. 교과서가 쓴 대로 쓰고, 고쳐 쓰지 않는다.

| 항목 | 규칙 | 예 |
|---|---|---|
| 맞춤법 · 띄어쓰기 | 교과서 원문 그대로 | 「소인수분해 한다」 (띄어 씀) |
| 용어 | 교과서에서 굵게 쓴 용어 그대로 | 소수, 합성수, 서로소, 절댓값 |
| 음의 부호 · 빼기 | `−` (U+2212). 하이픈 `-` 쓰지 않음 | −3, (+5)−(+3) |
| 양의 부호 | 교과서에 있으면 그대로 붙인다 | +4, (+1)+(+3) |
| 곱하기 · 나누기 | `×`, `÷` | 2×2×3, 8÷2 |
| 거듭제곱 | 위첨자 | 2³×5, 3²×5⁴ |
| 분수 | 화면에서는 세로 분수로 그린다 (`_tokens.css`의 `.frac`, 값은 design.md 4장 `frac-*`). md의 `a/b`는 세로 분수의 뜻 | −5/4 → 세로 분수 5 over 4 앞에 − |
| 부등호 | ≥, ≤, <, > | −2≤a<3 |
| 절댓값 | 세로 막대 | \|−3\|=3 |
| 단위 | 수와 단위 사이 한 칸 | 80 m, 4 ℃, 5 km |
| 문자 | 수식 글꼴(Noto Serif KR) 바로 선 글씨. 기울이지 않는다 — 기울인 글꼴 파일이 없고 글꼴은 유지하기로 함 (docs/design.md 3장, 2026-11-15) | a, x, y |
| 쪽수 | 「교과서 p.쪽」 | 교과서 p.42 |
| 동그라미 번호 | 교과서 그대로 | ⑴, ⑵, ➊ |

- md에서 내가 붙인 라벨 `(말풍선)`, `(옆 주)`, `[그림 …]` 설명은 교과서 원문이 아니므로 화면에 쓰지 않는다.
- 교과서 그림을 그대로 옮기지 않는다. 그림 설명을 보고 docs/design.md 6장 규칙으로 다시 그린다.

## 6. 부품

`src/parts/`의 7개 부품만 쓴다. 새 모양이 필요하면 부품을 새로 만들고 이 표에 적는다.

| 부품 | 쓰는 장면 | 한 영상에서 |
|---|---|---|
| `background.html` | 모든 장면의 맨 아래 | 처음부터 끝까지 하나 |
| `subject-label.html` | 모든 장면 왼쪽 위 | 처음부터 끝까지 하나 |
| `title-quote.html` | 첫 화면, 개념을 처음 말하는 장면 | 여러 번 |
| `definition.html` | 용어 정의 · 성질 정리 | 여러 번 |
| `figure-caption.html` | 수직선 · 도형 · 표를 보여 주는 장면 | 여러 번 |
| `year-era.html` | 큰 수 하나를 보여 줄 때 (연도, 큰 계산 결과) | 필요할 때만 |
| `verdict.html` | 짧게 판정하는 순간 (예: 「서로소!」, 「합성수」) | 장면당 한 번 이하 |
| 마지막 정리 화면 | `figure-caption.html`의 그림 조각 + `title-quote.html`의 제목 · 문장 조각을 위아래로 놓는다 (4장) | 맨 끝 한 번 |

- 한 화면에 부품은 `background` + `subject-label` + 내용 부품 1개. `verdict`만 다른 내용 부품 위에 겹칠 수 있다.
- 부품의 "건드리지 않는 것"(각 파일 맨 위 주석)은 장면에서도 바꾸지 않는다.
