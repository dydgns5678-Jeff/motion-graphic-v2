# make-video

수업 영상 한 편을 만드는 순서. 먼저 `CLAUDE.md`의 규칙 3개와 고정 · 참조 · 금지를 다시 읽는다.

- ✋ 단계는 선생님 승인 없이 넘어가지 않는다. 승인은 AskUserQuestion으로 받는다 (선택지: 승인 / 고칠 곳 말하기).
- 어느 단계에서든 에이전트가 "질문:"을 돌려주거나 문서에 없는 값이 필요하면 멈추고 선생님에게 묻는다. 값을 지어내지 않는다. 물을 때는 무엇이 · 어느 문서 몇 장에 없는지 · 레퍼런스에서 잰 후보가 있으면 그 값과 출처를 같이 보여 준다.
- 모든 산출물은 `out/<영상이름>/` 아래. `<영상이름>`은 짧은 영어 소문자 (예: `prime-composite`).
- 에이전트는 Agent 도구로 부른다: `content-editor`, `art-director`, `director`, `builder`, `critic`.

## 0. 브리프

선생님에게 묻는다 (AskUserQuestion, 질문마다 기본값을 첫 선택지로):
1. 소단원 — `docs/textbook/index.md`에서 "변환 완료"인 것 중에서 고른다. 변환 안 된 소단원이면 먼저 content-editor로 PDF 변환을 요청할지 묻는다.
2. 길이 — 기본값 60초 안팎.
3. 소리 — 기본값 "소리 없음". 음악 · 효과음 · 내레이션 값은 docs에 없으므로, 넣는다고 하면 무엇을 쓸지 따로 묻는다.
4. 꼭 넣을 것 · 뺄 것 (선택).

답을 `out/<영상이름>/brief.md`에 적는다.

## 1. 교과서 정리 ✋

- `content-editor`에게: brief.md와 소단원 md를 주고 `out/<영상이름>/content.md`를 만들게 한다.
- 결과의 핵심 1~3개, 화면에 쓸 문장 목록, 다시 그릴 그림, 애매한 곳을 선생님에게 보여 준다.
- ✋ 승인받는다. 고칠 곳이 있으면 content-editor에게 다시 맡긴다.

## 2. 레퍼런스

- `art-director`에게: brief.md · content.md를 주고 `out/<영상이름>/look.md`를 만들게 한다.
- look.md 4장(문서에 없는 값)이 비어 있지 않으면 멈추고 선생님에게 하나씩 묻는다. 답을 look.md 4장에 "선생님 답"으로 적는다.
- 질문이 없으면 승인 없이 다음으로 간다.

## 3. 장면표 ✋

- `director`에게: brief.md · content.md · look.md를 주고 `out/<영상이름>/scenes.md`를 만들게 한다.
- 장면표 표와 총 길이, "질문:" 목록을 선생님에게 보여 준다.
- ✋ 승인받는다. 승인된 scenes.md가 이후 모든 단계의 기준이다.

## 4. 스냅보드 ✋

- `builder`에게: 승인된 scenes.md로 HyperFrames 프로젝트 `out/<영상이름>/video/`를 만들고, 장면마다 머무는 구간 가운데를 한 장씩 찍어 `out/<영상이름>/snapboard/<장면번호>.png`로 남기게 한다. 움직임은 아직 대충이어도 된다.
- 스냅보드를 장면 순서대로 선생님에게 보여 준다 (SendUserFile).
- ✋ 승인받는다. 고칠 곳은 builder에게, 장면표를 바꿔야 하면 3단계로 돌아간다.

## 5. 생성 · 검수

1. `builder`에게: 움직임까지 다 만들고 `npx hyperframes check --json` 오류를 0으로 만들게 한다.
2. `critic`에게: 판정을 맡긴다. critic은 고치지 않는다.
3. critic 결과를 `out/<영상이름>/REVIEW.md`에 적는다 (회차마다 아래에 덧붙인다).
4. 불합격이면 어긋난 항목만 builder에게 넘겨 고치게 하고 2로 돌아간다.
5. 3회째도 불합격이거나 "판정 불가"면 멈추고 선생님에게 어긋난 항목과 근거를 보여 주고 묻는다.

합격하면 `npx hyperframes preview --background`로 미리보기 주소를 선생님에게 주고, 렌더해도 되는지 묻는다.

## 6. 렌더 ✋

- 선생님이 렌더해도 된다고 하면 `builder`에게 렌더를 맡긴다: `out/<영상이름>/<영상이름>.mp4`.
- builder가 `ffprobe`로 확인한 길이 · 1920×1080 · fps가 scenes.md와 맞는지 본다.
- 영상 파일을 선생님에게 보낸다 (SendUserFile).

## 7. 규칙 남기기

- 이번 영상에서 새로 정한 것을 모은다: look.md 4장 "선생님 답", REVIEW.md에서 되풀이된 어긋남, 선생님이 고치라고 한 것.
- 앞으로도 쓸 것만 골라, 어느 문서 몇 장에 무엇을 적을지 목록으로 선생님에게 보여 준다 (예: "docs/motion.md 4장에 '정의 화면 머무는 시간 3.0s' 추가").
- 승인받은 것만 해당 docs에 적는다. `docs/design.md` · `docs/motion.md` · `docs/video.md`는 고정 문서이므로 승인 없이 고치지 않는다.
- `docs/textbook/index.md`에 이 영상 이름을 적을지 묻는다.

## 끝

선생님에게 한 줄씩: 영상 파일 경로, 판정 회차, 새로 적은 규칙, 남은 질문.
